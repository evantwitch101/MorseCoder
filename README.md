# MorseCoder - Learn Morse Code with Flashcards

A modern, interactive web application for learning Morse code through flashcards. Practice characters, numbers, and common words with audio playback and visual representation.

## Features

- 📇 Interactive flashcards for learning Morse code
- 🔊 Audio playback of Morse code signals
- 👁️ Visual representation of dots and dashes
- 📊 Progress tracking
- 🎯 Multiple difficulty levels
- 📱 Responsive design

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Bootstrap or Tailwind CSS
- **Audio**: Web Audio API

## Project Structure

```
MorseCoder/
├── index.html          # Main entry point
├── css/
│   └── styles.css      # Custom styles
├── js/
│   ├── app.js          # Main application logic
│   ├── morse.js        # Morse code data and utilities
│   └── audio.js        # Audio playback functionality
├── data/
│   └── morse-data.json # Morse code reference data
└── README.md           # This file
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start learning Morse code!

## How to Use

- Click on flashcards to reveal Morse code
- Use the audio button to hear the Morse code signal
- Mark cards as learned to track progress
- Advance through different difficulty levels
